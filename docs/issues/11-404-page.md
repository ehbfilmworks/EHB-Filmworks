`docs/prd-initial-build.md`

## What to build

Build a 404 route styled like the other page-head'd pages. Big "404", subtitle "Diese Seite gibt's nicht — oder noch nicht.", primary button back to the homepage. GitHub Pages serves this for unknown URLs automatically when the file is named `404.html` in the build output.

## Acceptance criteria

- [ ] `src/pages/404.astro` exists and produces `404.html` in the build output
- [ ] Page uses the same `.page-head` background-trees + dark gradient pattern as Projekte/Preise/Kontakt
- [ ] Headline reads "404" (with `<em>` accent on the digits if it adds visual interest)
- [ ] Subtitle reads "Diese Seite gibt's nicht — oder noch nicht."
- [ ] Primary button labelled "Zurück zur Startseite" links to `/`
- [ ] Secondary link "Projekte ansehen" links to `/projekte`
- [ ] Page renders the global Nav and Footer chrome
- [ ] Verify at deploy time: `https://ehb-filmworks.ch/this-does-not-exist` serves the 404 page
- [ ] `<SEO>` populated with title "404 — Seite nicht gefunden — EHB Filmworks", `noindex` on the meta robots tag so search engines don't index 404s
